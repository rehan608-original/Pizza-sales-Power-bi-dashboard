# Executive Business Intelligence Dashboard: Pizza Sales Analysis

## Project Objective

The primary objective of this project is to analyze transactional sales performance and present actionable commercial insights[1][2]. By quantifying key financial metrics, evaluating purchasing trends across time, and identifying top and bottom menu items, the dashboard supports data-driven decisions regarding menu optimization, inventory allocation, and marketing strategies[1].
